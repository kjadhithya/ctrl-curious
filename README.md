# Ctrl+Curious

*A field guide to everything else.* A daily design digest, weekdays at 9:00 IST.

## Brand

| Token | Hex | Use |
|---|---|---|
| Ink | `#2E1F25` | Text, dark surfaces |
| Paper | `#F4EEE8` | Backgrounds |
| Mauve | `#C9A7B5` | Soft accents, text on dark |
| Plum | `#7E4B6B` | "Curious", secondary emphasis |
| Wine | `#8A2E3B` | Primary accent, the plus, labels |
| Clay | `#D9C3B7` | Borders, warm neutrals |
| Ochre | `#C8902F` | Accent only, use sparingly |

- **Logo:** Figtree ExtraBold, stacked `CTRL` + solid plus over `Curious`.
- **Type:** Source Serif 4 for everything else (Georgia fallback in email).
- **Texture:** fine paper grain on every surface.
