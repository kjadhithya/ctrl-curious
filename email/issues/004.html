>  Today, in brief
Apple's Pro and tell event on 28 October is expected to bring a redesigned MacBook Pro with an OLED touchscreen and Dynamic Island, which would make touch a real input for Mac interfaces. Two pieces sharpen the craft: Patrick Neeman argues critiques should run on cited principles and evidence, not taste, and SAP's Arin Bhowmick shows how to answer a CFO in payback and conversion terms. And a week after Config India, Nil Thyrion asks designers to own the experience people actually receive, not stop at handoff.
>  Tool of the day
Payload in Figma Make
When you prompt a site in Figma Make, it now scaffolds a Payload backend with a database, file storage, login, role-based access and an admin panel, hosted by Figma. It is best at getting a marketing or content site into the hands of editors who can change copy, swap images and review form submissions without a designer in the loop.

>  Tool to master
Figma Motion: styles, bulk edits and handoff
Motion has picked up custom animation styles, audio, per-character text animation and Lottie export. These moves turn it from a one-off animation canvas into a shared motion system that scales across files.
1
Save your easing, duration and other variable-backed values as an animation style, combine styles into a richer pattern, and publish them to a library so every file pulls the same motion.
2
For bulk changes, select all the frames and ask the agent to match the first frame's animation, or to switch every keyframe to a custom spring with 0.35 bounce while keeping values and timing.
3
To review a set together, select the frames, right-click and choose Frame selection, then press play on the parent frame.
4
Animate text by character, word or line and the layer stays editable, so copy changes don't mean rebuilding the motion.
5
Hand off from Dev Mode, where engineers copy the timeline as CSS, JSON or motion.dev, or export Lottie, dotLottie, or MP4 and WebM with audio.
 Our take  Motion is in open beta on any plan for anyone with edit access, so details may change. The agent steps use AI credits, which Figma started charging for when the agent became generally available on 6 October.
