>  Typeface spotlight
Redaction
Commissioned for The Redaction, Titus Kaphar and Reginald Dwayne Betts's 2019 work at MoMA PS1, it heightens the Times New Roman and Century Schoolbook of court papers with soft round terminals and razor-thin strokes. Google Fonts added it this month along with Redaction 10 to 100, cuts that get progressively rougher, like a document photocopied too many times.

Editorial headlines, pull quotes, civic and justice-themed products
>  Steal this
A safe starter for CSS random()
Drop this into a prototype to give cards or tags a hand-placed wobble that only appears where the browser supports it and stays flat for people who ask for less motion.
random-wobble.css
/* Flat by default */ .card { rotate: 0deg; } /* Only where random() exists */ @supports (rotate: random(-2deg, 2deg)) { @media (prefers-reduced-motion: no-preference) { .card { rotate: random(-2deg, 2deg); /* step of 2px keeps offsets on your grid */ translate: 0 random(-4px, 4px, by 2px); } } } /* Shared key: width and height get the same value */ .tile { width: random(--tile-size, 48px, 96px, by 8px); height: random(--tile-size, 48px, 96px, by 8px); }
Keep the ranges tiny for anything people read or click. A by step snaps values to your spacing scale, and a shared key keeps squares square.

>  10-minute brief
Controlled randomness in interfaces
CSS can now pick a value at random inside a range you set, so layouts can feel handmade without a script deciding every angle.
 random(min, max) returns a value between two bounds of the same unit, optionally snapped to a step with the by keyword, and a named key lets several properties share one result.
Where support stands
1
Safari
WebKit shipped random() first.
 
2
Chrome and Edge
Rolling out with Chrome 156.
 
3
Firefox
Not shipped yet, so plan a fallback.
How to design for it
01Randomise decoration, never structure: tilt a sticker or a card shadow, but keep body text, grids and tap targets fixed.
02Use a by step to snap random values to your spacing or rotation scale, so the mess still belongs to the system.
03Pair random() with sibling-index() for a fan or stack that is ordered first and only lightly jittered second.
04Wrap it in @supports with a static fallback, and flatten angles for people who prefer reduced motion.
05Hide per-letter spans from screen readers if you jitter individual characters.
Why it matters to you
Brand teams keep asking for warmth and imperfection; this gives you a way to spec it in tokens and ranges that engineers can ship without custom scripts.
