>  Today, in brief
Anthropic opened a research preview of Claude Duet, a proactive agent that sends a morning brief, keeps working in the background and asks before it sends, pays, signs or deletes anything. Early testers like Claire Vo find it polished but too quiet to become a habit, and Jakob Nielsen's latest roundup adds a rule every agent needs: a reliable way to stop a run without losing finished work. Apple Music unveiled a new identity with a logo shaped by sound, arriving with iOS 27.2 next week. And today's case study is the VS Code team's modern UI rollout, a lesson in refreshing a tool people use all day without breaking their muscle memory.

>  Case study
VS Code team, Microsoft
Modernizing the VS Code UI
A decade of one-at-a-time features had left the workbench inconsistent, so the team built shared tokens for spacing, size and colour, tried them first in the new Agents window, then rolled out through Insiders and a controlled Stable experiment. The decision that made it work: when users said a roomier layout meant less code on screen, the team added a Compact density instead of reverting, and kept the classic UI one setting away.

Randy Hunt has led design at Notion and Etsy, and on Design Better he explains why his teams stay smaller and flatter than people expect, and why he shields good people from busywork.
Habits worth copying
 
Keep the team deliberately small, so limited bandwidth forces you to choose what matters instead of doing everything.
 
Have designers ship code to production, as he set up at Etsy in 2010, long before design engineer was a common title.
 
Give small touchpoints like push notifications the same care as the main dashboard, an approach he calls whole design.

>  Decision toolkit
Should the agent ask first, or just act?
Proactive agents from Anthropic, Meta and OpenAI are arriving fast, and each one forces the same call: which actions run on their own, and which wait for a yes.
Let it act when
›  The result is a draft the person reviews, like a reply waiting to be sent
›  It only reads and summarises, like a morning brief of email and calendar
›  The step is easy to undo and lands where the person will look
 
Make it ask when
›  It speaks for the person to someone else, like sending a message
›  It moves money, signs something or deletes data
›  It would mark work as done; let only the person close a task
Seen in the wild
Claude Duet
Drafts replies for review, asks before it sends, pays, signs or deletes, and leaves finishing a task to you.
Rule of thumb  If it can't be undone or speaks for the person, ask first, and always offer a stop that keeps finished work.
