>  Today, in brief
Apple's first foldable goes on sale today, and reviewers agree the weak spot is software from other people: Engadget's review praises the multitasking but finds Telegram and Gmail floating in dead space on the inner screen. The apps that work, like Slack, Netflix and Spotify, lean on two panes, tabletop splits and side controls, much as Apple's own apps do with sidebars, dual panes and a dock on the right. Even Apple Books is moving to standard Liquid Glass controls in iOS 27.2, likely so they reposition on the Duo. And Framer opened its canvas to outside agents, so Claude, Codex or Cursor can now build and edit your Framer site directly.

>  Power-up
Framer MCP lets your AI assistant work inside Framer
Released on 22 October, Framer's official MCP server connects the assistant you already use to your Framer projects, so it can build and edit there instead of handing you code to paste. Changes stay editable on the canvas, and Framer doesn't need to be open.
Framer MCP  Framer · Free to connect · AI usage billed by your assistant
What it changes
●Your assistant can create pages and change layouts across desktop, tablet and phone breakpoints, reusing the project's own styles and components.
●It can create CMS collections and items, and import content from anything else it can reach.
●It can audit metadata, headings, alt text and page structure before you ship.
●Work can happen on a review branch, and nothing goes live until someone publishes.
Install it
In the Claude app
Open the Framer listing in the Claude Directory, choose Connect to Claude, sign in to Framer and approve access, then ask Claude to connect to your project.
Or, in Cursor or another client, add the server manually
Add a remote server named framer, type Streamable HTTP, with this URL, then connect and approve in the browser. In Codex, the command is below.
codex mcp add framer --url https://mcp.framer.com/mcp
Then try asking
 Connect to [project link]. On a new branch, build a pricing page from our existing components and text styles, then list any missing alt text or heading issues across the site.
 Our take  Ask for a branch every time: unlike the older CLI setup, MCP doesn't create one automatically. The agent acts with your account's permissions on every project you can access, and localisation isn't supported yet.
