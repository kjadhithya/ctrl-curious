>  Tool of the day
Canva Craft
Canva's first in-house image model works in two stages: one model plans the composition, elements and text, and a second renders it at up to 2K, with text in 55 languages and over 30 aspect ratios. It is best at layout-heavy graphics such as posters and social assets, where its structured output can be split into editable layers with Magic Layers.

>  Tool to master
Figma code layers: from frames to a working prototype
Code layers put running code on the Figma canvas, in open beta on all plans. Creating and editing them costs no AI credits on paid plans until 4 November, so this is the week to build a real workflow around them.
1
Pick your starting point: press B for an empty code layer and prompt the agent, or select one or more frames, choose Code and click Build selection to turn existing designs into a working prototype.
2
Bring in what already exists: paste a live page captured with the Figma Chrome extension, upload a local folder, or connect GitHub and clone a repo, working on a branch and opening a pull request to merge back.
3
Make precise tweaks without prompting: open the code editor, click Edit in the Browser tab, Shift-click elements in the preview, adjust colour, padding and type in the properties panel, then click Apply.
4
Press Play on several layers at once to compare versions side by side, and capture the empty, loading and error states that static frames tend to skip.
5
Use Extract designs to bring results back as editable frames: the current state, a single element, or Record a flow to turn a sequence of screens into frames, then push edits back to the code layer.
 Our take  After 4 November, code layer tasks use AI credits like other agent features, and other agent work in the same prompt is already charged. Imports can take ten minutes or more and not every repo will run, so test with a small project first. Creating code layers through MCP needs a Full seat.
