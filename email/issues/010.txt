Today, in brief
Design tools spent the week opening up to agents: Figma now lets Claude, Cursor or Codex call Weave's image and video models through its MCP server (https://www.figma.com/release-notes/?title=access-video-and-image-models-from-figma-weave-via-the-figma-mcp), and Code Connect 2.1 drops its setup wizard in favour of an agent skill (https://github.com/figma/code-connect/releases/tag/v2.1.0) for mapping components to code. Framer followed its MCP launch with an Assets panel that its own agents can organise (https://www.framer.com/updates/asset-panel). The catch, as the Design Systems Collective argues, is that cheap automated audits make every deliberate exception look like a bug (https://designsystemscollective.substack.com/p/some-mistakes-are-on-purpose), so systems need a way to record them. And with Apple's event tonight, the bigger interface question is what touch does to a desktop built for a cursor (https://www.forbes.com/sites/ewanspence/2026/10/25/why-apples-macbook-pro-touch-will-not-change-laptops-forever/), which today's brief takes on.
