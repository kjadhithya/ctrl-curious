>  Power-up
Replica turns the Copilot app into a prototyping tool that knows your design system
Released as open source on 28 October by GitHub Design and Microsoft CoreAI Design, Replica adds a canvas plugin to the GitHub Copilot app. Your team keeps its components, patterns and approved guidance in one prototyping repository, and every prototype is built from them, so what people generate looks like your product and not like a generic template.
Replica (replica-prototype plugin)  GitHub Design and Microsoft CoreAI Design · Free, MIT licence · models through a Copilot plan or your own provider
What it changes
●Prototypes are generated from your team's components and documentation, with designers approving the guidance the agent follows.
●The prototype opens in a canvas beside the Copilot conversation, so you describe a change, try it and refine it in one place.
●Finished prototypes can be published to a Replica Hub your organisation hosts, where teammates try them and leave comments, without needing a Copilot subscription.
●Because the starter, guidance and hub are open source, you can adapt them to your own product and review process.
Install it
In a terminal with Copilot CLI (or ask the agent to run it)
Sign in with gh auth login if you aren't already, add your team's prototyping repository to the Copilot app, then install the plugin. Afterwards, open Customize, then Installed, and enable the replica-prototype plugin and canvas.
copilot plugin marketplace add github/replica copilot plugin install replica-prototype@replica
Or, once per team
Someone creates the shared prototyping repository, adds the design system and guidance, and optionally deploys the hub, following the environment setup guide in the repository.
Then try asking
 Using our approved design-system guidance and sample data, prototype a project list with search, an empty-results message and a way to clear the search. Keep it separate from the live product.
 Our take  The canvas preview runs on macOS and Linux only, bring-your-own model is still in preview, and a self-hosted hub doesn't mean no data leaves your organisation. Treat what it makes as a way to test assumptions, not as the spec engineers build from.
