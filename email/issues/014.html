>  Today, in brief
Canva has released Affinity for iPad free for individuals, with sketch, vector, photo and layout work in one touch-first file, days after shipping Brush, a model that edits existing layouts instead of generating flat images. Framer's rebuilt agent harness now edits components, CMS, forms and branches in one pass, and gives outside agents the same reach through MCP. The craft lesson of the day comes from Victor Yocco, who shows why approving AI summaries leaves people unable to explain them and how to design friction that makes oversight stick. And X's head of design Benji Taylor has open-sourced Stageshow, a skill that teaches coding agents to make animated product demos that don't look fake.
>  Tool of the day
Stageshow
Benji Taylor, head of design at X, released this agent skill on 31 October to make coding agents better at faux UI: animated or static product illustrations for marketing pages and docs, built as editable React components with a scripted cursor, camera moves and themes that can map to your design tokens. It is best at the launch-page demo you would otherwise hand-animate, and it films its own output so the agent can check the motion, not just the final frame.

01The generation effect in AI workflows: why reviewing causes forgetting
UXmatters · ServiceNow researcher Victor Yocco applies a classic memory study to AI review flows: people who approve a polished AI report remember little of it, and read timers, citations and attestation boxes don't help. He offers four fixes worth stealing, from AI outlines with the conclusion left blank to a recall question before a high-stakes summary can be shared.
02Canva launches Brush, a model that edits designs instead of generating them
The New Stack · Brush reads a design's structure, writes small pieces of code to change it and checks its own result, so everything stays editable. It is in Canva Pro now, with brand kits and attachments promised next; the useful test, as one expert notes, is whether an edit leaves prices, disclaimers and layout alone.
03Affinity for iPad is here, and it's free for individuals
Creative Boom · Canva's iPad version of Affinity puts sketching, vectors, photo editing and layout in one .af file that also opens on desktop, with Sketch to Shapes turning Pencil strokes into editable vectors. Core tools are free; the AI features need a Canva premium plan, and some desktop features are missing at launch.
04Harness 2: Framer's agent takes on whole workflows
Framer · Framer rebuilt how its agent works so it applies changes while still planning, with half the tool steps. It can now edit component fields and animation settings, sort the CMS, set form destinations, manage branches and add SVGs, and outside agents get the same abilities through Framer's MCP server.
05User interfaces for multiple roles: when four users share one product
UXmatters · Anna Nazarevska of Volta Health on a regulated student-health platform used by admins, clinicians, brokers and students: one interface per role built around its decisions, friction that scales with the cost of an error, audit trails for risky changes and an AI assistant whose autonomy shrinks as the stakes rise.
>  Tool to master
Figma agent: turn your crit checklist into a skill that reads your docs
Two pieces of the Figma agent now fit together: custom skills, which save a set of instructions as a slash command, and connectors, which let the agent read other tools. With Google Drive now connectable on every plan, you can build a review that checks frames against the real PRD instead of your memory of it.
1
Write the skill once. In an agent chat, click the prompt box, choose Skills, then Add skill and Start from scratch, or ask the agent to turn a good conversation into a skill. The name becomes the command, such as /design-crit, and the help page advises phrasing when it should run as a requirement, not a restriction.
2
Connect your sources. Open Add context, choose Connectors, pick Google Drive (or Notion, Linear, Slack and others) and sign in. Set each tool to Ask to run while you test; tools that write to other apps stay off until you turn them on.
3
Combine both in one prompt. Type /design-crit, add the Drive connector with @ so it appears as a pill, and ask the agent to check the selected frames against the spec. When the doc changes, run the connector again so the agent sees the new version.
4
Share it with the team. In Manage skills, open More actions and choose Publish, then Private and your team or organization; later edits need Publish changes. Export saves the skill as a file you can also give your own coding agents.
 Our take  Skills must be a single Markdown file, with no scripts or reference folders, and if a prompt names several skills only the first runs. Full seats can use the agent in Design files, while View, Dev and Collab seats only get it in Drafts, and Google Drive isn't available with the Governance+ add-on. Start with the checklist your team already argues about in crits: it is the one most worth making consistent.
