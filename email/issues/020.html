Geist Serif
A high-contrast display serif with saw-toothed serifs and sharp hairlines, drawn after fashion and magazine titles and built on the same metrics as Geist Sans and Mono. An Element Shape axis swaps the dots on i, j and punctuation between round, square, triangle and heart; it shipped on 30 October with 894 glyphs covering 352 languages and was added to Google Fonts on 3 November.

>  Steal this
A prompt that sets up a private AI model on your Mac
Sil Bormüller's designer's setup guide shows how to run a capable model on an Apple Silicon Mac, so you can summarise interview notes or test UX copy without sending anything to the cloud. It ends with a prompt that has Claude Code do the whole setup for you; this is our condensed version of its seven steps.
local-llm-setup.md
Set up a local LLM on this Mac for design work. 1. Check memory, chip and macOS version. Stop if it is not Apple Silicon on macOS 14+. 2. Pick a model by memory, 4-bit MLX build only, leaving about a third of memory free: 8 GB Gemma 3 4B | 16 GB Gemma 4 12B 24 GB Qwen 3.6 27B | 32 GB+ Qwen 3.6 35B 3. Install LM Studio and its CLI if missing. 4. Tell me the download size, then download it. 5. Load it with a 32K context, start the server. 6. Ask one test question; report the answer and tokens per second. 7. Finish with three lines: which model, how to restart it, how to stop it. Explain each step in plain language. If a step fails, tell me; do not retry silently.
Paste it into Claude Code in an empty folder and approve each step as it asks. If you would rather click than type, follow the manual LM Studio steps in the guide and choose the model with the green full GPU offload badge.

>  10-minute brief
The agent harness: the part of an AI feature you actually design
Adobe, Framer and Figma all shipped agent news in the last fortnight, and the model was rarely the story. What changed was the harness around it: what the agent can see, what it may touch, and what people see while it works.
 An agent harness is the software around an AI model that runs its loop: it decides which tools and context the model gets, what it is allowed to change, and how its steps and results reach the person using it.
Where it showed up this week
1
Framer Harness 2
Framer rebuilt its harness so the agent applies changes while it is still writing, and tied what it may do to each person's role.
 
2
Adobe's Plan Mode
Firefly's Creative Agent now shows a plan to review and approve before it runs, with a model picker that can be left on auto.
 
3
Adobe's MCP preview
Outside agents will edit native Photoshop and Illustrator files with layers intact, so the harness, not the model, decides what stays editable.
How to design for it
01Show the plan before the run for anything that changes many items, and let people edit or drop a step, not just approve the whole thing.
02Map agent permissions to the roles you already have: someone who can only view should be able to ask questions but not trigger edits.
03Replace the long spinner with visible progress, so people can stop a run that is heading the wrong way before it finishes.
04Keep the agent's output in native, editable form, such as layers, components or CMS fields, so a person can fix one detail without rerunning everything.
05Give every agent change one clear undo, and say which model and which context it used when results look off.
Why it matters to you
As agents spread through design tools and the products you design, most of what users feel, such as speed, trust and control, comes from the harness, and those are interface decisions, not model choices.
