>  Today, in brief
Anthropic now lets partner apps open inside Claude, full screen or beside the chat, with Canva, Webflow and Adobe in the first set and Figma building one, so a product's own interface can now live inside someone else's AI app. At Adobe MAX, Project Link Up showed vector art that re-fits its perspective, scale and style to whatever scene you drop it into, and Webflow added native modals and popovers. Behind the design: Concept to Vector in Adobe Illustrator
Illustrator's trace tools need a clean, high-resolution source and return far more anchor points than a person would draw, yet most work starts as a rough sketch. The team built Concept to Vector, which turns sketches and low-fi images into editable paths, testing the interaction with a vibe-coded demo called Project Lightbox while engineering proved feasibility. The decision that made it work was making the prompt optional, after research showed most designers don't want to write one: people can start from a prompt, presets or adjustment controls, and Adobe says it is now Illustrator's most used generative feature.
>  How they work
BU
Buzz Usborne
Principal designer, Help Scout
In a Case Study Club interview and his own write-up, Help Scout's principal designer explains how he rebuilt a design system from 2018 so AI could read it, and why the accumulated decisions are what will set products apart.
Habits worth copying
 
Write the principles by hand, distil them into a design.md, then test it: ask for a simple screen with no context, judge the result, add one piece of guidance and run it again.
 
Make the system legible before asking for speed: he spent two weeks restructuring more than 200 primitives, standardising tokens and bringing Figma and React to parity with Code Connect.
 
Move fastest where a decision is cheap to undo, and spend the time saved on discovery; he still sketches on paper before opening a tool.
 Our take  The evaluation loop is the habit to copy this week: it needs nothing but an afternoon and a blank prompt, and it shows you exactly what your system never wrote down.
 
>  Decision toolkit
Which design skill should your coding agent get?
Dozens of repos now call themselves design skills for coding agents. Roman Kamushken compared 13 of them by the job they do and, more usefully, by how each one checks its own output.
A build-from-scratch skill when
›  There is no interface yet and you need a first full page
›  You want a direction quickly and will judge it, not ship it as is
›  It runs real checks, such as rendering at several widths before a review
 
A polish skill when
›  The code already sits on a design system you trust
›  The job is motion, transitions and small details
›  You need small changes a reviewer can read, not a rebuild
Seen in the wild
Hallmark
Renders a page at eight widths, then has a fresh-context review read it, which the comparison counts as a real check; some popular skills offer only a checklist, and one offers none.
Rule of thumb  If a skill can't tell you how it checks its own output, treat it as a style suggestion, and install only the one for this week's job.
 Our take  The two columns are our grouping of the article's five lanes; it also covers skills for exploring directions, adjacent artifacts like diagrams, and fake product UI.
