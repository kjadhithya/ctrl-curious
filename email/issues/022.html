>  Today, in brief
Figma now lets you rotate, tilt and add depth to layers natively, keyframe it in Motion and copy the result as CSS in Dev Mode, so card flips and perspective effects no longer need a plugin or a hand-made spec. Smashing gives teams a way to argue about AI with evidence: a four-question audit that asks whether a feature saves more effort than it costs people to check it, and whether they can still spot its mistakes after a year. Two shipped redesigns are worth studying: Microsoft's Xbox PC app puts friends in the main navigation and merges search, and Apple TV treats sign language as a setting, like captions, rather than a separate version of the film. For the weekend, Linear's Karri Saarinen makes the case for quality as strategy, and a new open-source skill called unslop teaches coding agents to fix AI-looking screens in a designer's order.

01Figma adds native 3D transforms, from rotation and depth to CSS in Dev Mode
Figma Learn · Released on 12 November for every plan with a Full seat: rotate on three axes, set depth, perspective, pivot and backface, keep nested layers in one 3D space for cubes and stacks, animate it in Motion, and hand off translateZ and perspective values straight from Dev Mode.
02Should you actually add AI to that? A four-question audit for product teams
Smashing Magazine · Victor Yocco's test for any proposed AI feature: does it cut total effort, beat what people do now, make its errors catchable, and keep users sharp enough to notice when it's wrong; he includes a 60-minute workshop format to run it with your team.
03Stop making people describe what they can point at
AI UX Playground · An interaction-pattern piece that splits an AI request into target, operation and constraints, and argues selection should carry the target and named verbs the operation, with patterns for text, code and images and a checklist for diffs, scope and local undo.
04Xbox PC app redesign reaches Insiders with new navigation, library and search
Mixed News · Microsoft moves friends and social into the main navigation, reworks library filters, puts games, add-ons and people in one search, and claims big speed gains; a useful look at how a large app reorganises its information architecture.
05Apple TV makes sign language interpretation a built-in accessibility feature
TechCrunch · Instead of a separate film, a human interpreter is a setting on the main title, marked with an icon beside captions and audio description and findable through search; a clear model for treating access as a layer, not a variant.
>  Power-up
unslop teaches your coding agent to fix AI-looking screens in a designer's order
Damir Sokolovsky's free skill for Claude Code, Codex and Antigravity turns vibecoded, AI-looking UI into a designed interface. It appeared on GitHub at the end of October and has been one of the fastest-climbing design skills since, so it is a good moment to point it at a screen you shipped in a hurry.
unslop  Damir Sokolovsky · Free, CC BY 4.0 licence
What it changes
●It audits first, listing the tells of AI-made UI, such as purple gradients, glows, emoji labels, shouty copy and uneven spacing, and where each one appears.
●It proposes a direction before touching pixels: a character, a world, accent moments and one signature detail drawn from your product.
●It fixes the screen in ordered passes, spacing, colour, icons, copy, type, layout, details, visuals and motion, rather than all at once.
●It works on Next.js, React, Vue, Svelte, Tailwind or plain HTML and CSS, and can start from a live site URL.
Install it
Claude Code, in your terminal
Clone the repo and copy the skill into your skills folder; for one project only, copy it into that project's .claude/skills folder instead.
git clone https://github.com/heydamir/unslop mkdir -p ~/.claude/skills && cp -r unslop/skills/unslop ~/.claude/skills/
Or, codex
Install it with the skill installer.
$skill-installer install https://github.com/heydamir/unslop/tree/main/skills/unslop
Then try asking
 Open a project and ask: /unslop this dashboard.
 Our take  Where Impeccable gives you a vocabulary and a detector, unslop is a single critique-then-fix pass with a point of view, so read its proposed direction before letting it run the passes. Image generation for hero visuals uses a paid service, and it asks before each one.
