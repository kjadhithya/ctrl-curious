Today, in brief
If you ship prototypes with real data, today's warning is that a scan of 159,041 Lovable projects found 24,664 apps returning database records without a login (https://www.trendingtopics.eu/lovable-apps-sensitive-data-exposed/), mostly because nobody set access rules. Jakob Nielsen reads a meta-analysis in which human and AI teams usually lost to whichever worked alone (https://www.uxtigers.com/post/ux-roundup-20261116), and a benchmark where models met almost every brief but produced designs that looked alike. Two UX Collective pieces give you something to act on: an edge-case checklist to hand an agent before it writes UI (https://uxdesign.cc/ui-edge-cases-a-reference-guide-e778061588ef), and a case for giving the human in the loop real authority (https://uxdesign.cc/decision-theatre-or-decision-design-f1604f178685) rather than an approve button. And a new plugin, Crossfade, lets Claude Code build with your own components (https://crossfade.company/) in the Figma file you have open.
