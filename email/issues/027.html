>  Today, in brief
Canva now lets Free and Pro users hide its generative AI features with one setting, a control only team admins had before, which is a useful precedent if your product is adding AI everywhere by default. Bitwarden's redesign is a lesson in naming: it swapped collections for shared folders after a month-long public beta, because people didn't understand the old words. Two pieces show where AI speed is leaving gaps: Level Access found that testing hasn't sped up the way design and build have, and zeroheight lists what to fix so agents can read your design system docs. For the weekend, a new free skill called craft makes coding agents write a brief and list every state before they draw a screen.

01Canva lets Free and Pro users switch off generative AI
Trending Topics · A new permission hides every feature that creates content with AI, and a second setting shows fewer AI-made templates and elements in search; Background Remover and Magic Grab stay on because they only edit existing images. Worth studying if you are deciding how much control to give people over AI in your own product.
02Bitwarden's redesign renames collections to shared folders and keeps your filters as you browse
Bitwarden · Rolling out from 19 November on web, desktop and the browser extension: a sidebar that separates personal, shared and pinned items, one search across both vaults, and plain names in place of jargon, tested in a public beta where 98% of respondents found their way without help.
03AI sped up the build: how can accessibility testing keep up?
Smashing Magazine · Level Access's Andrew Chung uses a survey of 2,500 practitioners to show AI sped up design and development far more than QA, then lays out where to put checks: at design handoff, at pull request gates and with a named owner for each fix.
04Fixing a low machine-readability score on your design system documentation
zeroheight · Luke Murphy's checklist for docs that agents can use: write out every variant and its allowed values, list keyboard behaviour key by key, publish tokens as a fetchable file, and on each look-alike component name the other one and when to pick it.
05Service as a software: the new SaaS is ahead of schedule
UX Tigers · Jakob Nielsen updates his 2024 forecast: AI vendors increasingly sell finished work priced per outcome, with examples from Intercom's Fin to Zendesk. He warns about counting a customer's silence as a success, which changes what designers need to show before and after an agent acts.
>  Power-up
craft makes your coding agent write a brief and list every state before it draws a screen
Diego Fernandes released craft on GitHub on 15 November, a free set of design skills for Claude Code, Codex, Cursor and other agents. Ask for a pricing page and, instead of jumping to pixels, the agent works like a careful designer: it agrees the scope with you, plans the states and keeps a record of decisions. It works with Paper, pen.dev or plain HTML, and has a Figma adapter that is still untested.
craft  Diego Fernandes · Free, MIT licence
What it changes
●A setup interview asks about product, audience, voice, mood and constraints one question at a time, then writes a DESIGN.md with a dated decisions log, tokens and base components, so choices made on Monday still hold on Thursday.
●Before drawing, it lists every state the screen needs, including empty, loading, error, long content, permissions and offline, filled with realistic messy data, and stops for your approval.
●When you ask for options, it draws three directions that differ in structure, interaction or density rather than colour, and recommends one.
●It renders and critiques its own work for hierarchy, spacing, contrast and consistency, and shows which screens a token or component change will touch before it spreads.
Install it
Claude Code
Inside a session, add the marketplace and install the plugin; in the Claude app, add the marketplace diego3g/craft from the plugins menu instead.
/plugin marketplace add diego3g/craft /plugin install craft@craft
Or, other agents such as Cursor and Codex
Install the skills with npx, naming your agent; add -g to install for every project, and paste the README's routing block into AGENTS.md.
npx skills add diego3g/craft -a cursor
Then try asking
 Run set up craft for this project, then ask for a settings page with billing and team, and see which states it lists before drawing.
 Our take  Unlike the anti-slop skills we have covered, craft doesn't push a style; it enforces a process, which makes it most useful on a real product with real edge cases. It is five days old, so expect rough edges, and use the tested HTML or Paper routes rather than Figma for now.
