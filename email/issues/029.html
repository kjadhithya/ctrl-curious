>  Today, in brief
Design work no longer has to stop at handoff: Google Labs' Stitch Loop watches a shipped product and opens pull requests to fix accessibility, speed and security, with nothing merged until a person reviews it. Two UX Collective essays tell you how to stay in charge of that kind of output: Patrick Neeman makes the case that the prototype should come before the requirements doc, and Tania Ostanina lays out guardrails for cleaning up AI-made screens from PMs and developers. On the shipped side, Claude's Android app now follows Material 3 Expressive while keeping its own colours, and Rockstar explains how the GTA 6 HUD kept its heritage and gained accessibility settings. If your files still mix old and new auto layout, Figma's switch-back option ends in January 2027, so today's tool to master is upgrading them safely.
>  Tool of the day
Stitch Loop
Google Labs opened the waitlist for Stitch Loop on 18 November: a long-running product agent that connects to your GitHub repo and live product signals (logs, behaviour, feedback, through 180+ integrations or your own MCP servers), suggests problems, proposes fixes with trade-offs and visual design options, builds them in a sandbox and opens a pull request with screenshots, then keeps watching the metric after the fix ships. It is best at running a standing accessibility or conversion loop on a product that is already live, so design quality keeps improving after handoff instead of decaying.

>  Tool to master
Figma's updated auto layout: upgrade old frames before January 2027
New frames in Figma have used an auto layout version that behaves like CSS flexbox since July, but existing frames stay on the legacy version until you upgrade them, and the option to switch back ends in January 2027. Most files now mix both, and a few rules have changed in ways that move things by a few pixels.
1
Upgrade in bulk, then check. Pick the new version from the layout version dropdown in a frame's auto layout settings, or open the Actions menu with Cmd/Ctrl+K and run Update layout version for selection or Update layout version for page; Figma previews any visual change before you confirm, and Cmd/Ctrl+Z undoes it.
2
Mind the padding floor. A frame can no longer shrink below its total padding, as in CSS border-box: with 30px padding on each side a 50px-wide frame renders at 60px and max width is ignored, so if something grows after upgrading, cut its padding.
3
Choose stroke position on purpose. Only inside strokes take up layout space now, like CSS borders; outside and centre strokes draw but don't push spacing, like outlines, and a parent's include strokes setting no longer passes to children, which is why a selected state with a thicker stroke can change size.
4
Use grid fr units for truly equal columns. Fill-container siblings now share space by their full box, so a child with more padding or a heavier stroke gets slightly more room; switch the parent to grid flow with fr units when columns must match exactly.
5
Expect two spacing changes. Auto gap never drops below zero, so children that don't fit stack from the start instead of overlapping (set a negative gap by hand if you want overlap), and a single child in a Between stack now sits at the start, while Around and Evenly keep it centred.
 Our take  The docs don't tie this to a plan. Instances can't be upgraded on their own, so update the main component and republish the library first. Our advice: before upgrading a big file, search it for single-child stacks with auto gap, mixed stroke positions and frames whose padding equals their size, since those are the ones that shift.
