>  Method of the week
Build a context library your AI tools can actually use
AI agents are only as good as the context you give them. NN/g studied how power users organise that context; here is the short version to set up this week.
01Keep a small index file in each folder that says what is inside and when to use it.
02Load only what the task needs: start the session at the folder that matches the work, and keep project rules inside the project so they don't leak into everything.
03Keep files short, a few hundred lines at most, so nothing irrelevant loads every time.
04Let the agent make the edits: state what changed and ask it to update the files, then judge it by the quality of later output.
05Review it regularly against recent notes and decisions, and check that connected tools and links still work.

>  Prompt of the week
A persona critique with the Figma agent
The Figma agent can now critique a design from different personas and run accessibility checks. Select a frame, press Cmd or Ctrl + Enter, and try this:
Prompt  ·  Figma agent
> Critique the selected screen as three people: 1. a first-time user on a small phone, 2. a screen reader user, 3. an expert who uses this screen every day. For each, list the three biggest problems, the layer name, and one specific fix. Don't change anything yet.
Ask it to apply only the fixes you agree with. You can undo its most recent change.
Use it for
—  Catching blind spots before critique
—  A quick accessibility pass on a new screen
 
Not for
—  Replacing tests with real people
—  Final calls on brand or tone
