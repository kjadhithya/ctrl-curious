>  Steal this
A starter DESIGN.md for your design system
Google's open DESIGN.md format gives AI tools one file to read your design system from: tokens at the top, the reasoning in plain words below. Copy this starter, fill in your values, and lint it.
DESIGN.md
--- colors: primary: "#7E4B6B" text: "#2E1F25" surface: "#F4EEE8" typography: heading: { family: "Source Serif 4", weight: 700 } body: { family: "Source Serif 4", size: 17 } spacing: { s: 8, m: 16, l: 32 } --- ## How to use colour Primary is for one main action per screen, never for decoration. ## Buttons Use {colors.primary} with {colors.surface} text.
Then run: npx @google/design.md lint DESIGN.md (checks broken token references and WCAG contrast). The format is still in alpha.

>  10-minute brief
What MCP means for designers
Last week it went from developer jargon to something designers touch every day.
 A standard plug that lets an AI assistant work directly inside other tools, reading and changing real files instead of just chatting about them.
Where it showed up this week
1
In your design tool
The Figma agent can use MCP connectors, and Figma partnered with Sarvam on an India-first MCP integration at Config.
 
2
In your prototypes
ProtoPie's Studio MCP lets an agent build and check interactions in your open prototype.
 
3
In handoff
ProtoPie's Code MCP hands a finished prototype to engineers' coding agents, read-only.
Why it matters to you
Your files are becoming something agents read and act on. Clear names, real components and tidy structure now pay off twice.
