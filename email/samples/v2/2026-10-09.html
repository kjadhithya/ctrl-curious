>  Power-up
Skill creator: turn your team's checklist into a Claude skill
The fastest way to stop repeating yourself to Claude. This skill helps you package a way of working, like your critique checklist or handoff notes, into a skill Claude picks up on its own.
skill-creator  Anthropic · Free
What it changes
●Interviews you first: what the skill should do, when it should kick in and what it should produce.
●Writes the SKILL.md, including the description Claude uses to decide when to load it.
●Can run test prompts with and without the skill so you can compare the results side by side.
●Improves it from your feedback, explaining the reasons behind each rule instead of piling on rigid ones.
Install it
In the Claude app
It comes with paid plans. Check it is switched on in your Skills settings.
Or, in Claude Code
Add Anthropic's skills, then install the example set:
/plugin marketplace add anthropics/skills /plugin install example-skills@anthropic-agent-skills
Then try asking
 Use the skill creator to turn our design critique checklist into a skill. Here it is: [paste your checklist].
 Our take  Start with something you explain to Claude every week. If you've typed it three times, it should be a skill.
